# 人工验收清单（尚未执行）

本次按仓库规则不由 AI 启动桌面程序或服务做界面验收。以下请在新版安装后执行。

1. 保存正在编辑的内容，退出 CLI-Manager（包括托盘），重新打开安装目录中的程序。不要同时从源码开发模式和安装目录打开两个版本。
2. 在资源管理器复制一个文件或多个文件，回到文件面板，单击目标文件夹后按 **Ctrl+V**。确认文件落在该文件夹中，文件名/内容保留，源文件仍在。
3. 复制含子目录的文件夹，右键目标目录选 **粘贴 / Paste**；确认目录层级完整。资源管理器的“剪切”也按复制导入，不删除原位置。
4. 用截图工具复制一张截图（不是仅复制图片网址），选中目标目录后粘贴。应出现 `screenshot-日期-时间-唯一后缀.png`，可正常打开；重复粘贴生成新名称。
5. 选中文件后 Ctrl+V，应落在其父目录。点击列表空白处再粘贴，应落在项目根目录。树形、紧凑目录链、文件名搜索、代码搜索、侧栏和嵌入面板分别检查。
6. 重名时先弹确认；取消不改变旧文件；确认只重试冲突项。**文件夹覆盖为整体替换，不是合并**。在编辑器制造未保存的目标文件，确认不会被覆盖。
7. 先在应用内复制/剪切，再去资源管理器复制另一份文件或截图，返回粘贴：应使用新系统剪贴板。只复制文字再在文件面板粘贴，应提示没有可粘贴文件，不误贴旧文件。
8. 在搜索框、重命名框、编辑器和终端中粘贴文字，原行为不变。在应用内多选复制/剪切、拖到文件夹、拖到终端，既有功能不变。
9. 大目录复制中切换项目/Worktree，不得将旧目标的相对路径用于新项目；最多完成已经开始的单项操作，剩余项报告取消。SSH 仍不提供写操作。
10. 在设置中分别切换 **简体中文 / English**，检查 Paste、空剪贴板、占用、重名和错误提示；两种语言的时间显示保持 24 小时制。检查浅/深主题、紧凑侧栏、分屏、最小化后恢复。
11. 如使用 WSL/UNC/Worktree，再用真实目录重复文件/截图导入。权限不足、链接、已消失目录应报错，不进行目录越界写入。
12. 原有 Live Server、历史会话、项目配置与终端会话恢复仍正常。

## 已知范围
- 本次主要目标为 Windows；文件列表读取使用 Windows 原生剪贴板。SSH 不做上传。
- 图片导入限制：1200 万像素、PNG 最大 64 MiB。既有文件预览仍有自己的 5 MiB 图片限制。
- 文件/图片写入的是所选项目目录，不是会在两天后清理的终端临时附件。
- 文件批次非事务：分别显示成功/失败/冲突；已成功项不会因其他项失败而自动撤销。
- 系统剪贴板忙或在读取过程中变化时提示重试。异常发布回滚失败会保留 `.cli-manager-import-<uuid>/previous` 并显示恢复路径，勿删除该目录。
